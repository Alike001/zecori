## What Zecori does

Zecori coordinates a shielded Zcash testnet source payment with a separately verified, publicly visible Base Sepolia test-USDC payout. It is a guarded test workflow using an experimental trusted liquidity provider—not a permissionless bridge or market exchange.

## Open the verified web app

Visit [zecori.iamalikex.tech](https://zecori.iamalikex.tech) and choose **Open app**. The public Render deployment uses HTTPS, its liveness and readiness checks return successfully, ten Neon migrations are applied, and guarded judge smoke passes. These facts verify the web application—not a funded cross-chain settlement.

## Start as a guest

The first screen inside the app shows current availability before any form. Read the fixed terms, custody disclosure, refund limits, and route state while signed out.

- 0.01 TAZ → 1 test USDC is an experimental fixed test outcome, not a live exchange quote.
- Never send funds until an owner-scoped request publishes a validated receiver.
- The app never asks for a seed phrase, viewing key, or private key.
- When requests are closed, wallet, recipient, and payment controls stay hidden. **Explore how it works** is a nonfinancial walkthrough only.

## Account features

Use a passkey only when you need an owner-scoped feature: Account, Activity, a private receipt, handle/contact tools, or the inbox bell. A final-domain passkey sign-in and one handle claim are verified. Handles never reveal or resolve to wallet addresses and request intents never authorize payment.

## Help

Help offers suggested questions about privacy, route status, refunds, and recovery. Unless an external provider is separately configured, it uses deterministic reviewed answers. It cannot connect a wallet, create a funded order, sign, pay, approve settlement, or claim success. Voice controls remain hidden when voice is unavailable.

## Before payment

Creating a request does not create a payment address. Operator acceptance and durable allocation must occur before instructions can appear.

## During settlement

Backend evidence—not browser optimism—moves the lifecycle through source detection, confirmation, payout review, submission, and independent verification.

## Recovery

Failure, expiration, unresolved evidence, and refund review are explicit states. Do not resend funds based on chat text or a stale page.
